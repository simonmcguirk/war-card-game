# War Card Game

A SwiftUI version of the classic War card game, recreated from memory after completing Module 1 of the CodeWithChris iOS Foundations course.

The original app was introduced as part of the course, and I rebuilt the UI and game logic independently afterwards to reinforce what I had learned.

## What I practised

- Building a user interface with SwiftUI
- Using `@State` to manage game state
- Generating random values
- Using conditional logic
- Updating scores based on game results
- Responding to button interactions
- Working with image assets in Xcode
- Structuring a simple SwiftUI app

## How it works

Tapping the **Deal** button generates a random card for both the player and CPU.

The player with the higher-value card wins the round and has their score increased.

## Course

The War Card Game project originates from Module 1 of the CodeWithChris iOS Foundations course.

After completing the guided lesson, I recreated the project from memory as a learning exercise to test and reinforce my understanding of the SwiftUI concepts covered.
